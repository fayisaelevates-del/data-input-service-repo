## How to Find PR URLs in GitHub

For future reference, you can find PR URLs by:

1. **Direct Navigation**: Go to `https://github.com/{owner}/{repo}/pulls`
2. **From Branch**: When you push a branch, GitHub often shows a "Compare & pull request" button
3. **Via GitHub CLI**: Use `gh pr list` or `gh pr view {number}`
4. **Via Git**: Use `git log --oneline` to find commit messages that reference PR numbers
